FASE 1 Pengenalan Konsep VPS & Cloud

Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia.

Shared Hosting

Layanan hosting di mana banyak website berbagi satu server fisik dan sumber daya (CPU, RAM, bandwidth) yang sama. Biayanya paling murah dan mudah dikelola, namun performa terpengaruh jika trafik pengguna lain melonjak.

Dedicated Server

Penyewaan satu server fisik secara utuh khusus untuk satu pengguna/organisasi. Memberikan performa maksimal, keamanan tinggi, dan kontrol penuh atas perangkat keras, namun biayanya mahal dan butuh keahlian teknis tinggi.

Amazon Lightsail

Layanan VPS (Virtual Private Server) dari AWS yang dirancang praktis dengan paket harga tetap bulanan (bundling compute, storage, dan transfer data). Cocok untuk pemula atau aplikasi web skala kecil hingga menengah.

Amazon EC2

Layanan komputasi awan (IaaS) utama AWS yang menyediakan kapasitas server virtual (instance) yang sangat fleksibel dan dapat diskalakan (auto-scaling). Pengguna bebas mengatur spesifikasi CPU, RAM, jaringan, dan keamanan secara mendalam.
FASE 2 Persiapan dan Provisioning Server

Beri tanda centang pada kotak setelah Anda berhasil menyelesaikan setiap tahapan di konsol AWS.

  • Mengaktifkan akun AWS dan login ke Management Console.
  • Memilih Region AWS terdekat (misal: ap-southeast-1 / Singapore).
  • Memilih Amazon Machine Image (AMI), misalnya Ubuntu 22.04 LTS.
  • Memilih Instance Type dalam batas Free Tier (misal: t2.micro / t3.micro).
⚠️ PENTING: Manajemen Key Pair Saat melakukan provisioning, AWS akan meminta Anda membuat Key Pair. File berakhiran .pem atau .ppk ini adalah "kunci rumah" server Anda. Simpan file ini di tempat yang aman. Jika hilang, Anda akan kehilangan akses ke dalam server.

FASE 4 Konfigurasi Sistem Operasi & Web Server

Pasangkan perintah Linux berikut dengan fungsi yang tepat dengan menuliskan hurufnya.

1. sudo apt update ( C )
A. Menampilkan seluruh file termasuk yang tersembunyi.
2. sudo systemctl restart apache2 ( D )
B. Mengubah hak akses file menjadi read-only.
3. ls -la ( A )
C. Memperbarui daftar paket repositori OS.
4. chmod 400 key.pem ( B )
D. Memuat ulang layanan web server.
Tugas Praktik Web Server:
  1. Instal Apache atau Nginx pada server Anda (sudo apt install apache2 -y).
  2. Buat file index.html kustom di direktori /var/www/html/.
  3. Buka IP Publik server Anda di browser.

Checklist Deployment Akhir:

  • Mengunggah file website menggunakan SFTP (FileZilla/Cyberduck) ke direktori web.
  • Memastikan propagasi DNS selesai (domain dapat diakses di browser).
  • Menginstal Let's Encrypt (Certbot) dan mengaktifkan HTTPS.
FASE 6 Manajemen, Monitoring & Backup

Pemeliharaan server sangat penting. Gunakan AWS CloudWatch untuk melihat status server Anda dan dokumentasikan metrik saat ini.

Langkah Backup (Snapshot):
  1. Buka menu Volumes di konsol EC2.
  2. Pilih Volume server Anda.
  3. Klik Actions > Create Snapshot.
  4. Beri deskripsi dan simpan.
